# Threat Modeling Suite

Comprehensive threat modeling and data flow diagram (DFD) analysis tool implementing STRIDE/PASTA methodologies for security architecture design and risk assessment.

## Overview

Security architecture design tool for identifying and mitigating threats during the design phase. Enables architects to model system architecture, identify attack surfaces, and apply threat modeling frameworks (STRIDE, PASTA) for comprehensive risk assessment.

## Key Features

- **Data Flow Diagram (DFD) Builder**: Interactive system architecture visualization
- **STRIDE Threat Analysis**: Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege
- **PASTA Methodology**: Process for Attack Simulation and Threat Analysis
- **Threat Library**: Pre-built threat patterns and mitigation strategies
- **Risk Scoring**: CVSS-based threat prioritization
- **Architecture Review**: Design phase security validation
- **Export/Reporting**: DFD diagrams, threat matrices, mitigation recommendations

## Key Components

- Interactive DFD canvas (actors, processes, data stores, flows)
- Automated STRIDE threat identification per element
- Risk assessment and prioritization matrix
- Mitigation tracking and validation
- Security architecture patterns library
- Architectural review checklists

## Installation

```bash
git clone https://github.com/Korir555/threat-modeling-suite.git
cd threat-modeling-suite
pip install -r requirements.txt
```

## Usage

1. **Create DFD**: Define system actors, processes, data stores, data flows
2. **Apply STRIDE**: Analyze each element for applicable threats
3. **Score Risks**: Assign likelihood and impact ratings
4. **Plan Mitigations**: Define controls and mitigation strategies
5. **Generate Report**: Export DFD, threat matrix, recommendations
